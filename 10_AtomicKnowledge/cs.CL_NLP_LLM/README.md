# cs.CL - Computation and Language (NLP & LLM)

> 自然语言处理与大语言模型 | arXiv: [cs.CL](https://arxiv.org/list/cs.CL/recent)

## 📚 领域概述

本目录收录 NLP 与大语言模型相关的原子笔记，下设四个二级目录：

- `Embeddings/` — 词嵌入（Word2Vec、GloVe 等静态词向量）
- `Pretrained_Models/` — 预训练模型（BERT 等）
- `LLM_Training/` — LLM 训练（预训练、对齐、后训练）
- `LLM_Inference/` — LLM 推理与分析（推理能力、不确定性、上下文工程）

## 🔗 相关领域

- `cs.IT_InfoTheory/` — 熵、KL 散度、交叉熵损失
- `ml.DL_DeepLearning/` — Transformer、注意力机制
- `ml.AL_Algorithms/` — 迁移学习、终身学习
