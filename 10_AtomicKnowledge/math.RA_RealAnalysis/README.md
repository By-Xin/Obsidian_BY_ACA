# 实分析 (Real Analysis)

> 领域代码: math.RA | 测度论、拓扑、极限理论

## 📚 领域概述

实分析是现代分析学的基础，研究实数系统上的极限、连续性、可测性等基本概念，为概率论和统计学提供严格的数学基础。

- `math.OC_Optimization/` — 优化理论中的分析工具
- `stat.IN_Inference/` — 统计推断
