# 机器学习算法 (Machine Learning Algorithms)

> 领域代码: ml.AL | 统计学习、经典算法、集成方法

## 📚 领域概述

本目录涵盖各类经典机器学习算法，包括线性模型与回归、分类算法、非参数方法（树模型、样条）、集成学习、核方法，以及迁移学习、元学习、终身学习等学习范式。

## 🔗 相关领域

- `ml.TH_Theory/` — 学习理论
- `ml.DL_DeepLearning/` — 深度学习
- `stat.IN_Inference/` — 统计推断
- `math.OC_Optimization/` — 优化算法
