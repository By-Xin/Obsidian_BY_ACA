# 统计推断 (Statistical Inference)

> 领域代码: stat.IN | 参数估计、假设检验、非参数统计

## 📚 领域概述

统计推断研究如何从样本数据中推断总体特征，包括点估计（充分性、完备性、UMVUE、CR 下界）、渐近方法与常见的非参数检验。

## 🔗 相关领域

- `math.PR_Probability/` — 概率论基础
- `stat.TS_TimeSeries/` — 时间序列分析
- `ml.AL_Algorithms/` — 统计学习方法
