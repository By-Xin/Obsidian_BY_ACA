这个目录用来放最近读到的 SPO / decision-focused learning / portfolio optimization 相关文献笔记。建议保持一篇文献一个文件，先抓住它对你当前研究线索的价值，再补技术细节。

## File naming

建议使用：`AuthorYear - short title.md`

例子：

- `Elmachtoub2021 - Smart Predict then Optimize.md`
- `AnisKwon2025 - E2E Cardinality Portfolio.md`

## Reading note checklist

- 一句话 takeaway：这篇文献解决了什么问题，和你的 SPO 线索有什么关系？
- Problem setup：输入、决策变量、目标函数、约束、训练信号分别是什么？
- Method core：作者真正的新东西在哪里？loss、relaxation、solver layer、理论还是实验？
- Assumptions：哪些假设在你的场景里可能不成立？
- Evidence：实验设置、baseline、公平性、可复现性。
- Reuse：哪些公式、图、表、证明套路或实验设计可以放进 talk / paper / code？
- Questions：读完之后还没解决的问题。
