# 相关对话的整理

## Baseline 如何构建

> Julia 代码为纯 vibecoding 结果, 仅供参考.

总体而言的 baseline 应当分为如下两层：(对于第 $t$ 时刻, $h$ horizon, 第 $a$ 个资产, 预测收益 $\hat{r}_{t+h,a}$ , 对应持仓权重 $X[h,a]$)

- 同一个 downstream LP 下的算法 baseline
  - Zero+LP / Risk-only LP (作为下界 baseline)
    - 设预测收益全部为 0, $\hat{r}_{t+h,a} = 0, \forall h, a$. 仅仅通过 LP 模型的风险约束来进行投资组合优化. 这个 baseline 可以作为一个下界 baseline, 因为它完全没有利用任何预测信息.
  
        ```julia
        # =========================
        # Zero+LP
        # =========================
        predict_cost_zero(ds) = zeros(length(ds.c_true))

        function evaluate_lp_baseline(decision_samples, predict_cost_fn)
            regrets = Float64[]
            for ds in decision_samples
                c_hat = predict_cost_fn(ds)          # 预测成本向量
                x_hat = ds.oracle(c_hat)             # 走你现有的下游求解器
                regret = dot(ds.c_true, x_hat) + ds.fixed_cost(x_hat) - ds.z_star
                push!(regrets, regret)
            end
            return regrets
        end
        ```
  - Historical Mean 20 + LP
    - 取历史最近 20 天的平均收益 $\hat\mu_{t,a}=\frac{1}{20}\sum_{k=0}^{19} r_{t-k,a}$, 作为未来每一天的预测收益, 复制给每个 horizon $h$: $\hat{r}_{t+h,a} = \hat\mu_{t,a}, \forall h$. 这个 baseline 是一个非常常见的时间序列预测方法, 可以作为一个简单的基准来评估更复杂的预测模型的性能.
  
        ```julia
        # =========================
        # HistMean20+LP
        # =========================
        flatten_stage_matrix(X::AbstractMatrix) = vec(permutedims(X))

        function predict_cost_histmean(ds; W_pred::Int = 20)
            # ds.history_returns: W x A
            R = ds.history_returns
            W = size(R, 1)
            A = size(R, 2)

            W_use = min(W_pred, W)
            mu = vec(mean(R[end-W_use+1:end, :], dims=1))   # 长度 A

            H = length(ds.c_true) ÷ A
            Rhat = repeat(reshape(mu, 1, A), H, 1)          # H x A

            return -flatten_stage_matrix(Rhat)
        end
        ```
    - 也可以考虑将上述历史平均换为指数加权平均 $\hat\mu_{t,a}^{EMA}=\frac{\sum_{k=0}^{19}\beta^k r_{t-k,a}}
{\sum_{k=0}^{19}\beta^k}$. 其中 $\beta$ 作为超参经验常设为 0.94 或 0.97. Historical Mean 20 和 EMA 可以选一个就行.

        ```julia
        function predict_cost_ema(ds; W_pred::Int = 20, beta::Float64 = 0.94)
            R = ds.history_returns
            W = size(R, 1)
            A = size(R, 2)

            W_use = min(W_pred, W)
            Rsub = R[end-W_use+1:end, :]

            w = beta .^ (W_use-1:-1:0)
            w ./= sum(w)

            mu = vec(w' * Rsub)                            # 长度 A

            H = length(ds.c_true) ÷ A
            Rhat = repeat(reshape(mu, 1, A), H, 1)

            return -flatten_stage_matrix(Rhat)
        end
        ```
  - ETO
  - SPO+-SGD / SPO+-DSA
  - Oracle LP: 作为当前数据, 市场表现, 风险模型约束下等能够达到的理论最优. 理论上, 我们也可以考虑每个其他模型距离这个 Oracle 的差值(贴近程度)来衡量这个策略的好坏.

- 外部视角的 trading baseline
    - 1/N periodic rebalancing: 同样是在外部策略视角下的一个 baseline. 
      - 1/N 方法: 有 N 个可投资资产，每个都投同样比例。它不需要预测收益，也不需要估协方差。
      - 参考论文: How Inefficient is the 1/N Portfolio Strategy? (https://drive.google.com/file/d/1c8CJey9xDXrLiRnUmw2xFumFibi-Yp9E/view?usp=drive_link) 
      - 作者比较了 14类资产配置模型，在 7组真实数据集 和一组模拟数据上做样本外检验， 没有任何一个模型能稳定地在 Sharpe 比率、确定性等价收益（CEQ）、以及换手率三个维度上持续优于 1/N.

        ```julia
        # =========================
        # 1/N baseline
        # =========================
        function plan_equal_weight(H::Int, A::Int)
            return fill(1.0 / A, H, A)   # H x A
        end
        ```

## 为什么 acc wealth 出现下降趋势

- 当前策略强制要求 long-only + fully invested, 不允许做空或者持有现金躲避市场下行期风险。 
- 测试集 2022-01-04 到 2023-12-29，这 100 只股票做最简单的等权日再平衡，gross wealth 大约只有 0.893，也就是不带任何模型，光持有这个 universe 都是往下的。
